# CRATE JUICE / JuiceWeaver identity

The crate mark identifies the family; the woven audio strokes distinguish this studio. Cream, ember and dark ink follow the owner's chlomim studio reference. `src/config.js` controls the application's colors, background, display font, optional logo and motion. Shared tokens and brand rendering live in `foundation/`.

`icon.svg` and `share.svg` are editable source assets. PNGs are rendered derivatives. Keep meaningful artwork inside the maskable icon's central safe zone. Update these static files and the manifest when changing product identity. The social card is metadata only; native sharing is deferred.

The name and visual system are design work, not a trademark clearance or registration. No rights or software license have been selected on the owner's behalf.
